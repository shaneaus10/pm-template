# Go-to-Market / Positioning

Positioning and messaging for anything this PM produces that faces customers, partners, or the market. Optional — use it if your initiatives have an external-facing story to tell.

This folder has **no keys** — it's narrative, not graph artifacts. But it should stay consistent with the personas (`1-personas/`) and value props (`2-value-props/`) that anchor the "who" and "why."

## Suggested contents

- `positioning.md` — the one-liner, the audience, the differentiation.
- `messaging.md` — key messages per persona/segment.
- `naming.md` — product/feature names and how to use them.

## Conventions

- Ground claims in real value props: reference `[VP-001]` rather than inventing new benefits here.
- Keep external messaging honest to what the artifacts actually promise.
