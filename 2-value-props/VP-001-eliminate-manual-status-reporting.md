# VP-001: Eliminate Manual Status Reporting Toil

> **📎 EXAMPLE ARTIFACT — delete or adapt during onboarding.** Part of the shipped example chain (P-001 → VP-001 → … → EPIC-001). Fictional data.

## Statement

Give the [P-001] Operations Lead an always-current status picture that assembles itself, so the weekly leadership report takes minutes instead of hours and never ships stale.

## Description

Today, status reporting is a manual reconciliation job: chase teams, copy updates, resolve conflicts, hand-format an email. It's slow, error-prone, and the output is stale the moment it's sent.

This value proposition reframes reporting as a **pull, not a push**: status lives where the work happens, and the report is generated on demand from a single reconciled source. The Operations Lead moves from *assembling* the report to *reviewing and acting on* it.

The win compounds — accurate, timely status means blockers surface earlier, and leadership trusts the numbers.

| Persona | Relevance |
